| 配置项         | 配置值                                                       |
| -------------- | ------------------------------------------------------------ |
| 选择训练模板   | 自定义                                                       |
| 镜像仓库       | registry-cn-guian.midea.com/aios/a3_llm_release:v2.1.3-aimp  |

| 实例数         | 按需，当前样例选择：2                                        |
| 开启RDMA网络   | 否                                                           |
| 分布式训练框架 | Pytorch                                                      |
| 环境变量       | 无                                                           |
| 运行命令       | 脚本启动命令                                                 |
