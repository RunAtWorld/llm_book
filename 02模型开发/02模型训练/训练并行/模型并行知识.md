# 模型并行知识

## 训练场景
关键计算公式
```
总卡数 = DP * TP * PP * CP
Global Batch Size = Micro Batch Size * 梯度累计 * DP
Epoch * 数据集条数 = Global Batch Size * Step数
```

注意：
* Micro‑Batch Size：一次前向过程中，一个 DP 域下 TP 组内每张 GPU 拿到的数据样本数量。
  * "Micro-Batch" 指的是流水线上流动的一个数据小块（通常等于 Micro Batch Size 个样本）
* GBS 必须可以被 MBS × DP 整除；GBS 本身并不强制是 PP 的倍数，但 DP‑PP 组合下：GBS ÷ (MBS × DP)**（也就是梯度累积次数 GA）必须是 PP 的倍数**，等价推出：GBS 需要是 DP × PP × MBS 的倍数。
